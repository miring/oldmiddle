# 표현 원칙

사업자등록은 결혼중개업이 아니라 **통신판매업**으로 합니다. 업종은 이름이 아니라 실제 서비스 모습으로 판단되므로, 화면 문구와 기능 모두 '결혼을 목적으로 운영자가 상대를 골라 소개하는 곳'으로 보이면 안 됩니다.

이 문서는 지금 코드와 앞으로 만드는 모든 화면에 적용합니다. 화면 문구와 기능을 만들거나 고칠 때 이 문서를 따릅니다.

## 쓰지 않는 말 → 대신 쓰는 말

| 쓰지 않는 말 | 대신 |
| --- | --- |
| 결혼, 중매, 성혼, 결정사, 재혼(상대 찾기), 혼처, 맞선 | 인연, 진지한 만남, 동반자 |
| 중개, 알선, 주선, 매니저, 큐레이션 | 추천, 약속 잡기 |
| 운영자가 (직접) 골라 소개, 골라 드려요 | 조건이 맞는 분 중에서 한 번 더 살펴봐요 |
| 성사 수수료, 성혼료, 가입비, 심사비 | 추가 수수료 없음, 가입 심사 무료 |
| 시니어, 노년, 어르신, 외로운, 마지막, 늦은 | 내 또래, 45세 이상, 편안한, 새로운 인연 |
| 서비스명 '시연' 단독 | 화면에서는 시연(時緣) (`site.serviceName` 사용, 알림톡·문자 제목만 예외) |

- '혼인 상태 서약', '혼인관계증명서', '독신 확인'은 기혼자를 거르는 안전장치라 써도 됩니다.

## 기능 규칙

- 만남 목적 선택지는 '진지한 교제 / 동반자 / 친구부터'만 둡니다 (`src/config/copy.ts`의 `MEETING_PURPOSE_OPTIONS`). '결혼'이나 '결혼 의향' 항목을 만들지 않습니다.
- 운영자가 회원의 연락처를 전달하지 않습니다. 번호는 두 사람이 모두 원할 때만 서비스가 공개합니다.
- 약속 시간과 장소는 시스템이나 운영자가 정해 주지 않고, 두 사람이 후보 중에서 고르게 합니다.
- 운영자가 사람을 골라 보내는 기능은 베타(무료)에서만 씁니다. 유료 운영에서는 자동 추천만 하고, 운영자는 점검만 합니다.
- 운영자가 직접 골라 소개하고 상담하는 상품(큐레이션)은 만들지 않습니다.
- 약관의 서비스 정의는 "회원 간 만남을 위한 정보 제공 및 약속 관리 서비스"로 씁니다.

## 자동 검사

`npm run check:copy`가 화면 문구에 '쓰지 않는 말'이 있는지 검사합니다. `npm run lint`에서 함께 돌고, GitHub Actions(`.github/workflows/deploy.yml`)의 lint 단계에서 실패하면 배포가 멈춥니다.

- **검사 대상:** `src/**/*.ts`, `src/**/*.tsx`의 문자열·템플릿 문자열·JSX 글자, `index.html`의 `<title>`과 `<meta content>`
- **검사하지 않는 것:** 코드 주석(설명하려고 금지어를 적을 수 있음), import·export 경로
- **예외:** 꼭 필요한 경우만 `scripts/check-copy-allow.json`에 파일(`file`)·문구(`text`)·이유(`reason`)를 함께 적습니다. 그 파일에서 `text`가 들어간 문자열만 통과합니다. 더는 쓰이지 않는 예외는 검사가 알려 주니 지워 주세요.
- **금지어 목록:** `scripts/check-copy.mjs`의 `BANNED`에 있습니다. 위 표를 고치면 함께 고칩니다.
